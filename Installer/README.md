# Learner installer

Run from the repository root on the developer PC, after committing reviewed changes:

```powershell
.\server\deploy\build-installer.ps1
```

Output: `artifacts/release/MosWord2019-Setup-1.0.0.exe` and its entry in `SHA256SUMS.txt`. The script rebuilds Release with the existing production public identity, runs compiled-trust verification, packages through the C7 eight-file allowlist, compiles Inno Setup 6, and extracts the installer to compare every runtime filename and SHA-256. It never executes Setup or an uninstaller. Existing release files are replaced only after payload verification. Intermediate evidence remains under ignored `artifacts/`.

Prerequisites: Visual Studio MSBuild/.NET Framework 4.7.2 targeting pack, an accepted production `artifacts/client-production/*/public-trust.json` receipt with its checksum, and Internet if build tools are absent. Inno Setup 6 is located automatically; if absent, the script runs the requested per-user winget install. A tested InnoUnpacker console build is downloaded from its upstream release and checked against pinned archive/executable SHA-256 values. These tools are build-time only and are not shipped to learners. An explicit `-InnoExtractPath` supports a compatible alternate extractor/test double; the automatic path uses InnoUnpacker because innoextract 1.12-dev cannot parse the installed Inno 6.6.1 header reliably.

`Version.props` is the single product-version source for MSBuild and ISCC. Keep the AppId in `MosWord2019.iss` permanently stable. Increase the product version there for future releases; no trust/key rotation is part of installer building. The approved PNG is byte-for-byte source artwork (owner confirmed hash `3b0040fb2c45f0fdc9be68b1905d14b7ea013046db0166a90230d7728432373a`); regenerate the ICO with `powershell.exe -NoProfile -File Installer/generate-icon.ps1`. Nine alpha PNG frames preserve source proportions, with transparent padding as needed.

The wizard uses the vendored Vietnamese translation from the official Inno source repository's `is-6_6_1` tag. The original translation and license are retained verbatim under `Languages/`; see its README for URLs and SHA-256. All product-specific messages are Vietnamese. InnoUnpacker may generate an `install_script.iss` inspection report beside extracted files; it is metadata generated by the inspector, not an installed file. Exactly eight runtime files under `{app}` must match the verified build.

Automated checks (no installation/uninstallation):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Installer/test-icon.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File server/deploy/tests/windows-build-installer.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File server/deploy/tests/windows-installer-definition.ps1
```

The definition checks compile Setup and exercise native directory guards on disposable fixtures. Never run the produced Setup/uninstaller on the developer's evidence profile. The user-data cleanup is uninstall-only, limited to the exact LocalAppData application root and Documents working subtree, refuses reparse nodes and pins ancestors while traversing; an upgrade never calls it. Silent uninstall is refused so the data-loss consent cannot be skipped. Learner instructions: `docs/HUONG_DAN_CAI_DAT.md`.
