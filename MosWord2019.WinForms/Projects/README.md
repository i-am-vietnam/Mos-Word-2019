# Production project packages

This is the only source root for learner project packages. Future packages use
`Word2019_Pnn` directories and are copied to the executable's `Projects`
directory by the WinForms project.

Word2019_P01 contains the user-supplied starter and eight EN/VI task instructions.
Its assertionType values are future schema identifiers only; grading is not implemented.
Never edit starter.docx in place. Training opens only the prepared work.docx copy.
